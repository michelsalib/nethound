# Code of conduct

nethound follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, and keep discussions about the work.

To report unacceptable behavior, contact the maintainer, [@michelsalib](https://github.com/michelsalib),
privately. Reports are handled confidentially.
